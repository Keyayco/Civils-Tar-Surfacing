# Civils Tar Surfacing Contractors Polokwane — static demo

Independent sales demo by Devign Digital. It is not approved, commissioned or endorsed by the business. The page uses vanilla HTML, CSS and JavaScript; no build step or server is required. Keep `index.html`, `style.css` and `script.js` together. All local file references are relative, so the folder can be served from a GitHub Pages subpath.

## Publish on GitHub Pages

Copy `index.html`, `style.css` and `script.js` to the repository root or its `/docs` folder, then choose that branch/folder under **Settings → Pages**. No build command is needed. Keep the three files together; replace the stock-image and sharing-image URLs before launch if the business supplies approved assets.

## Test on Android / mobile

1. Open the deployed preview URL in Chrome on an Android phone, or serve this folder on your local network and open that address on the phone.
2. Check the narrow layout, scroll links, menu open/close using touch and keyboard where available, and confirm the phone, map and direct WhatsApp links.
3. Fill in all four enquiry fields and submit. Confirm that WhatsApp opens with the complete enquiry prefilled; cancel before sending during testing. The form does not submit to a server.
4. Check the page at a larger viewport and with reduced motion enabled in the device accessibility settings.
